## Featured projects

### [MoneyFlow](https://github.com/drissakov/moneyflow)

**Personal finance · Android + custom API · MVP**

An income and expense tracker with multiple accounts, categories and subcategories, and monthly charts. Supports 11 currencies, portfolio valuation and a currency converter using Frankfurter exchange rates.

- Android client with a local Room cache and session storage backed by Android Keystore.
- Go API with PostgreSQL, registration, sign-in and idempotent transaction writes.
- OpenAPI, migrations, Docker Compose and GitHub Actions checks.

**Stack:** `Kotlin` `Jetpack Compose` `Material 3` `Coroutines / StateFlow` `Room` `Retrofit / OkHttp` · `Go` `Gin` `GORM` `PostgreSQL` · `Docker` `Caddy` `GitHub Actions`

### [QueueLess](https://github.com/drissakov/QueueLess)

**Appointment booking for small businesses · In development**

A foundation for an appointment booking SaaS. The current stage includes a responsive landing page, a health endpoint and Cloudflare Workers deployment configuration. Database clients and a Better Auth factory are prepared; authentication flows and booking functionality are planned next.

**Frontend:** `Next.js 16` `React 19` `TypeScript` `Tailwind CSS 4` `shadcn/ui` `Radix`

**Backend foundation and infrastructure:** `Neon PostgreSQL` `Drizzle ORM` `Better Auth` `Zod` `OpenNext` `Cloudflare Workers`

[View the landing page ↗](https://queueless.queueless.workers.dev)

## Web and learning projects

### [EsportsHub](https://github.com/drissakov/EsportsHub)

**Esports website · Academic team project**

A responsive, six-page frontend prototype covering events, teams, players, sample rankings and a community section. The mobile menu and carousel use CSS. My contribution: **the home page and events section**.

**Stack:** `HTML5` `CSS3` `Bootstrap 5.3` `Flexbox` `CSS Grid` · Static website without a backend.

### [Defense Lab](https://github.com/drissakov/web-midterm-preparation)

**Web development study guide and practice lab**

A Russian-language guide for a web project defense: **32 topics, 12 quiz questions and 36 defense questions with answers**. Includes interactive Flexbox and Grid examples, an EsportsHub walkthrough, a glossary and print styles. Works offline, with CSS-powered interactions.

**Stack:** `HTML5` `CSS3` `Flexbox` `CSS Grid` `:has()` `details / summary` · No JavaScript or external dependencies.

### [Marine Battle](https://github.com/drissakov/FinalProject)

**Battleship · Python desktop · Academic team project**

A graphical Battleship game for playing against a computer opponent that chooses random moves, or a second player on the same computer. Supports manual ship placement and rotation, hit and victory detection, and move history in JSON and CSV.

My contribution: **the computer opponent, file handling, unit tests, regular expressions, decorators and generators, and GUI integration**.

**Stack:** `Python` `Tkinter` `unittest` `JSON` `CSV`

### [University OOP](https://github.com/drissakov/unioop)

**Student management system · Academic OOP project**

Models students, teachers and groups, with search, filtering and sorting. The console application supports CRUD through JDBC and PostgreSQL. The web portion includes a GET/POST API and a simple interface; the add-student form integration still needs work.

**Stack:** `Java 17` `Spring Boot 3.3` `Maven` `PostgreSQL` `JDBC` `HTML` `CSS` `JavaScript`
